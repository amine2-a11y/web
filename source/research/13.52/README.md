# Firmware 13.52 research artifacts

These files are imported from the PS4 security-research project supplied alongside HENloader_Source.

- `1352_offsets_partial.txt`: partial/unverified 13.52 kernel offsets.
- `webkit_gadgets_1350.js`: WebKit gadget reference for 13.50; not claimed as a 13.52 gadget table.
- `1304.c` / `1304.h`: 13.04 reference offsets.

These artifacts are kept separate from the existing exploit/loader chain. They do not constitute a verified 13.52 jailbreak and are not wired into `Lapse.java`, `Poops.java`, or `KernelOffset.java` as executable 13.52 support.
